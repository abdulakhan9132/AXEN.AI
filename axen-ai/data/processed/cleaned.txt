AXEN is a tiny language model built from scratch.
It learns from tokens and predicts the next token.
Each layer uses attention to focus on context.
The model is small, local, and educational.
This project demonstrates the full pipeline.

A language model reads text and turns it into tokens.
The tokenizer maps characters to IDs.
The transformer mixes context across the sequence.
Training uses next-token prediction.
Generation then writes new text one token at a time.
