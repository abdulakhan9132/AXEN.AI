What this inspection can tell you

Axen recognizes source patterns and resolves local JavaScript, TypeScript and Python imports. It records basic symbols for Java, Go, Rust, C/C++, C#, PHP, Ruby, Swift and Kotlin. It does not decompile binaries or prove runtime behavior. Comments and strings may produce false matches.

Hidden folders, credentials, dependencies, generated assets and user data are skipped. Large projects are capped; inspect a smaller folder when coverage is partial.
